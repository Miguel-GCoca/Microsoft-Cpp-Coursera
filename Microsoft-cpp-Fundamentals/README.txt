Welcome to the capstone project for your C++ Programming Fundamentals course! In this comprehensive lab, you'll create a command-line utility tool that brings together all the key concepts you've learned throughout this course. This project will demonstrate your understanding of C++ fundamentals including syntax, data types, operators, control flow, and proper program structure.

Your task is to design and implement a multi-function utility program that users can interact with via a text-based menu. This project will test your ability to apply C++ concepts to create a practical, working application that could actually be useful in real-world scenarios.

🎯 Learning Outcomes
By completing this project, you will:

- Apply fundamental C++ syntax and structure in a comprehensive program
- Implement multiple functions that handle different tasks
- Create a user-friendly command-line interface
- Practice proper input validation and error handling
- Follow C++ best practices for code organization and documentation

📋 Requirements
Your command-line utility tool must include:

- A main menu interface that allows users to select between at least 4 different utility functions
- At least 4 distinct utility functions (examples below)
- Proper input validation for all user interactions
- Clear feedback to the user about operations and errors
- Well-organized and commented code that follows C++ best practices

💡 Suggested Utility Functions
Choose at least 4 functions from the following categories (or create your own):

Calculators:

- Basic calculator (addition, subtraction, multiplication, division)
- Mortgage/loan payment calculator
- BMI calculator
- Temperature converter
- Text Utilities:
- Word and character counter
- Text case converter (uppercase, lowercase, title case)
- Simple text encrypter/decrypter
- Palindrome checker
- Number Processors:
- Prime number checker
- Number base converter (binary, decimal, hex)
- Statistical calculator (mean, median, mode)
- Fibonacci sequence generator

Other Utilities:

- Random password generator
- Simple file information utility
- Unit converter (length, weight, volume)
- Date difference calculator
